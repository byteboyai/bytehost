# v0.4.23 — shared settings dialogs and Git accounts

The shared settings stack now includes the product-neutral dialog lifecycle,
geometry, Git account state and view, and injectable Git account services.
Digger and Dozer can compose their own pages and storage namespaces using the
same shell and contracts. All bytehost crates continue to use this git tag;
crate package versions remain unchanged.

## Reliability fixes

- Retain native child-window ownership and report creation / binding failures.
- Expose fallible native / GPU initialization and consumed-event / IME state
  for product adapters, so retry and Escape follow the shared lifecycle.
- Serialize each provider's credential + metadata commits and reject stale
  requests after waiting; keep cancellation independent of credential I/O.
- Surface credentials with missing metadata and allow reconnect / disconnect.
- Dismiss application confirmations before closing the settings dialog.
- Include bytehost-git-accounts in candidate consumer builds.

Credential service names, provider keys and persisted account schemas stay
unchanged. Consumers must adapt AccountSnapshot literals to the additive
unreconciled_providers field. Network and Keychain backends remain optional.

## Validation

- Clean release clone, without personal path patches: formatting, Clippy
